# کدهای کتاب «یادگیری مبتنی بر گراف»

از کاوش گراف تا شبکه‌های عصبی گرافی — سهیلا اشکذری طوسی، مصطفی توکلی، صنم ایرانی و زهرا حامد لبافیان.

این مخزن شامل **۸۱ برنامه‌ی مستقل** در هشت پوشه‌ی فصل است: کد کامل همه‌ی **۴۶ مثال شماره‌دار** کتاب، نمونه‌های کامل GCN و MPNN پیوست، و برنامه‌های تکمیلی برای بخش‌ها و تمرین‌های محاسباتی. دو برنامه‌ی پیوست همان فایل‌های مثال‌های ۷-۴-۱ و ۷-۵-۲ هستند و دوباره شمرده نشده‌اند. کادرهای اصلی برای ردیابی در [بایگانی کدها](docs/original-listings.md) نگهداری شده‌اند؛ برنامه‌های قابل اجرا در پوشه‌های فصل‌ها قرار دارند.

برنامه‌ی آموزشی برای یک ادعای نظری، جای اثبات عمومی را نمی‌گیرد. تمرین‌های صرفاً نظری پاسخ‌نامه‌ی کامل ندارند. برای مثال‌های توصیفیِ بدون داده‌ی مشخص، داده‌ی مصنوعی و فرض‌های افزوده‌شده در فایل توضیح داده شده‌اند. نمونه‌های بانکی حاوی داده‌ی واقعی مشتریان نیستند.

## نصب

محیط آزموده‌شده: **Python 3.10.18 روی Windows، CPU**. نسخه‌های دقیق وابستگی‌ها در requirements ثبت شده‌اند؛ نتیجه‌ی اجرا روی دیگر سیستم‌ها هنوز تأیید نشده است.

```powershell
git clone https://github.com/S-Ashkezari/GraphMachineLearning-BOOK.git
cd GraphMachineLearning-BOOK
py -3.10 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install torch==2.0.1 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
```

در Linux یا macOS، محیط را با `python3.10 -m venv .venv` بسازید و با `source .venv/bin/activate` فعال کنید. فرمان نصب wheel پردازنده‌ی مرکزی بالا برای Windows/Linux است؛ در macOS از `python -m pip install torch==2.0.1` استفاده کنید. نیاز به نصب GEM نیست؛ مثال‌های GF و HOPE با NumPy پیاده‌سازی شده‌اند. این پیاده‌سازی‌های آموزشی، بسته‌ی رسمی GEM نیستند.

## اجرا و نام‌گذاری

```powershell
python chapter_01/example_1_3_1_adjacency_distance.py
python chapter_02/example_2_2_9_pagerank_limit.py
python chapter_07/example_7_4_1_gcn.py
python chapter_08/section_8_3_6_gnn_link_prediction.py
python run_all.py --jobs 2
python run_all.py --chapter 5
```

- `example_2_2_9_...` به مثال ۲-۲-۹ اشاره دارد؛ شماره با شمارنده‌ی مشترک تعریف‌ها و مثال‌های کتاب تطبیق یافته است.
- `exercise_02_...` تمرین ۲ در همان فصل است.
- `section_8_3_4_...` برنامه‌ی بخش ۸-۳-۴ است.
- نمودارها بدون بازشدن پنجره، در `outputs` داخل پوشه‌ی همان فصل ذخیره می‌شوند. داده‌ی پایه‌ی نمونه‌ها در خود برنامه یا کتابخانه‌ی نصب‌شده موجود است و اجرای مثال‌ها دانلود داده نمی‌خواهد.
- seed ثابت تا حد امکان تنظیم شده است. پایه و علامت بردارهای SVD و خروجی آموزش تصادفی ممکن است بین محیط‌ها متفاوت باشند؛ برابری عددی خام مختصات شرط هم‌ارزی بازنمایی نیست.
